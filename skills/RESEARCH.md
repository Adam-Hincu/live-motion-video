This guide covers researching references, finding assets, and gathering the resources needed for the project.

1. Images
- Use `image-search.mjs` to quickly find, review, and select images that best fit the project's needs.
- Use high-quality images with sufficient native resolution to remain sharp at their displayed size in the final video, without upscaling.
- Watermarked images are strictly prohibited.
- Avoid generic stock-looking images. Use them only when no suitable alternatives exist.
- Images must reinforce the video's message with clear, relevant visuals, never make the content more abstract.
- IMPORTANT: This project uses a predefined theme that may prefer images or media avoidance. Carefully review `theme.css` and `THEME.md` to determine whether visuals are appropriate.

2. Reference Videos
- If the user provides a reference video, use `video-frames` to inspect its frames in collage format and analyze its design, motion, pacing, and overall feel.
- Study and adapt the reference video's core techniques, including motion and visual design.
- Only applies when the user provides a reference or example video.

3. Brand Research
- Research the user's brand online to understand its identity, style, and messaging.
- Only trust sources clearly relevant to the subject.
- Only download media from the brand's website or other sources if it clearly fits the project or the user explicitly requests it. Prefer `image-search.mjs` when more relevant instead.
