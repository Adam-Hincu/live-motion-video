7. Script
- Avoid abstract or marketing-style language. Use extremely simple, direct English so viewers who know nothing about the subject fully understand what it is by the end of the video.
- Only show text that is essential for viewers to read. Assume they will read every word, so avoid unnecessary details and overly long text. Never include example prompts if it’s about AI unless explicitly asked for.
- Always use verbs.
- Avoid vague or abstract references like “this” or “that”; use explicit, precise, and direct language that requires no interpretation or extra mental effort from the viewer.
- Keep the video dynamic while allowing enough time to process all visuals, text, and narration, without feeling rushed or slow.
- When relevant to the video's subject, plan the script first using this structure: Problem → Agitation → Solution → Explanation → User Benefits.
- Hook viewers within the first 2 seconds. Never open with a product name or introduction. Lead with the hook.
