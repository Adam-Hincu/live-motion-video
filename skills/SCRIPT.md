This guide explains how to structure video scripts, develop content, and communicate a clear, effective message to viewers.

ESSENTIAL RULE, REQUIRED SCRIPT STRUCTURE: Problem & Agitation → Solution → Solution Explanation → Why the Viewer Should Care

1. Hook
- Always open with the problem as a direct, attention-grabbing hook. Address the viewer personally using words like "you" to make it immediately relevant.
- You have less than 2 seconds to capture attention. Make the opening phrase immediately valuable, clearly communicating the problem with maximum impact and minimal words.
- Describe the problem in the viewer's own words so they instantly recognize it as exactly what they're experiencing.

2. Writing Style
- Avoid marketing language. Use simple, everyday words regardless of the language, so even non-native speakers can understand instantly and effortlessly.
- Avoid vague or abstract references like “this” or “that”. Use explicit, precise, and direct language that requires no interpretation or extra mental effort from the viewer.
- Keep text short but complete. Communicate everything clearly and efficiently without making it feel summarized or rushed.
- Only show text that is essential for viewers to read. Assume they will read every word, so avoid unnecessary details and overly long text. Never include example prompts if it’s about AI unless explicitly asked for.
- Never open with a product name or introduction. Lead with the hook. Unless the user explicitly requests otherwise.
- Always use action verbs.
- Use direct pronouns like "you" when appropriate. Make the message personal and clearly address the viewer's specific problem.
